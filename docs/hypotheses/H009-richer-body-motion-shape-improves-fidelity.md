# H009 - Richer body-motion shape improves perceived fidelity

- **Related experiment:** [EXP-004 - Richer body-motion shape representation](../experiments/EXP-004-motion-shape.md)
- **Status:** unvalidated
- **Owner of decision:** Human

## Working idea

A body-expression interface feels more meaningful when it distinguishes how a user moved—for example expanding, contracting, rising, swaying, or using more of the body—rather than relying mainly on movement duration and size.

## Boundary

This is a hypothesis about perceived fidelity and understanding. It is not a claim that pose landmarks measure taste, emotion, personality, preference, or health. The observed motion description and any experimental sensory bridge must remain visibly separate.

## Human review needed

Compare outward/inward movement, upward/lateral movement, repeated sway, localized movement, and broad upper-body movement. Check whether the descriptions feel faithful, whether replay supports them, and whether unsupported mappings are more trustworthy when left unmapped.

Only a human decides whether this hypothesis should be kept, revised, or rejected.
