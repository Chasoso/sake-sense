# Product vision (current working direction)

## Status

This is an experimental working direction, not a final product specification. Product usefulness and the interaction design remain subject to human review through experiments.

## User problem

A beginner may enjoy sake but still struggle to describe a taste, remember what made a bottle enjoyable, understand specialist terms, compare sakes, or explain a difference in a later conversation. The working problem is not simply that beginners lack sake vocabulary. They may have sensations but lack a bridge from those sensations to language, memory, comparison, and conversation.

## Current product idea

Explore whether a person can start with a nonverbal or pre-verbal expression—such as onomatopoeia, pointer movement or gesture, sound, or rhythm—and then move toward a shared sensory representation and sake-related language:

`nonverbal expression -> shared sensory representation -> sake-related language`

The working principle is:

> Nonverbal expression is not a replacement for words; it is an entrance toward words.

This is a hypothesis to test, not an accepted claim. The project should not treat any mapping between a gesture, sound, or onomatopoeia and sake terminology as scientifically validated without evidence.

## Ishikawa connection

The experience should retain a meaningful connection to Ishikawa sake and sake culture. It must not depend on a complete database of every Ishikawa sake brand. If product-specific data is needed, start with a small, well-sourced set and distinguish public web information from genuinely open and reusable data.

## Demo context

The hackathon or demo experience must work without serving alcohol. Participation must not require drinking. Actual drinking may later offer an optional richer path, but it is not the only path.

## Deliberately undecided

The final interaction, the role of each input modality, the sensory vocabulary, product-data model, AI usage, and hosting architecture are not decided here. Future Issues and human experience reviews should update this document when evidence changes the working direction.
