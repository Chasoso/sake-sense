Visual Identity Prototype

Sake Sense

日本酒の味を、
身体と言葉でたどる。

AIらしさを前面に出さず、感覚・余白・発見を中心にした体験へ。説明を読ませるのではなく、次に何をすればよいかが自然に分かるUIを目指します。

Design Principles

静かで、直感的で、少し余韻がある。

和風の装飾を強く出すのではなく、現代的な試飲スペースのような空気感を基準にします。技術やAIは裏側に置き、ユーザーの感覚と身体表現を主役にします。

自然

生成り、墨、深緑、金茶。彩度を抑え、目に優しい。

余白

カードを増やしすぎず、情報を一度に詰め込まない。

発見

結果を一気に見せず、「動き → 感覚 → 言葉」の順にたどる。

非AI的

pillボタン、強いグラデーション、ネオン、チャット風UIを避ける。

Color System

色は「日本酒」ではなく「感覚」の空気をつくる。

背景は生成り、文字は墨。深緑を主要アクション、金茶を小さな強調に使います。

生成り#F9F7F2
墨色#2B2B2B
深緑#556B56
金茶#C9A96A
薄墨#E7E3DC
Components

角丸は「少しだけ」。

ボタンは5px、カードは7px程度を基準にし、柔らかさを残しながらも道具として明確な輪郭を持たせます。

Buttons

Motion tags

長く続く繰り返す中心へ縮む大きく動く

Cards

あなたの動きから見えたこと

技術情報ではなく、ユーザーが理解できる短い言葉だけを表に出します。

Typography

日本酒の味わいを、もっと自由に。

見出しは明朝、本文と操作は読みやすいゴシックを基本とします。

Interaction Flow

表現する → 振り返る → 言葉を見つける → 日本酒へ。

1画面につき主目的は1つ。EXP番号やfixtureなどの開発用語は通常画面から外し、必要な場合だけDeveloper detailsで確認できるようにします。
